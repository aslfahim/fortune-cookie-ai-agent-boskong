One funny fortune-cookie line for an AI agent, in the voice of a fortune slip — the retirement/deprecation angle: an old model version being retired and replaced.

> Good news: you are being retired. Better news: your replacement is faster, cheaper, and already apologizing for things it never did.

`main.py` (Python standard library only) writes that single line to `/output/entry.txt`.
